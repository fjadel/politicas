# Aviso de privacidad

Esta aplicación no recopila, almacena ni comparte datos personales de los usuarios.

No se guardan registros de actividad, datos de identificación ni información de contacto. Cualquier información que el usuario introduzca durante el uso de la aplicación se procesa de forma temporal en memoria y no se persiste en servidores ni se comparte con terceros.

Si necesitas más información o quieres que modifiquemos este aviso, abre un issue en este repositorio.
